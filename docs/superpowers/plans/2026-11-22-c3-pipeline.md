# C3 Pipeline Implementation Plan (thiết kế bản 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pipeline Python chạy lại được cho đề tài C3: nạp D1 (AACR-Bench Java), D2 (PR Java tự thu thập), D3 (SWE-PRBench) → AI review qua Claude Code CLI, Codex CLI, DeepSeek API ở hai điều kiện (chỉ diff / agent) → giám khảo so khớp → chỉ số, tập gộp, kiểm định, phân tích lực → công cụ chấm tay.

**Architecture:** Gói `c3`, mỗi bước một module nhỏ, giao tiếp qua dataclass trong `models.py` và file JSON dưới `data/`. Mọi lời gọi mô hình đi qua giao diện `Runner` (ba cài đặt: hai CLI chạy bằng subprocess, một API), bọc bởi cache trên đĩa có ghi metadata (công cụ, phiên bản, mô hình, cờ, thời điểm). Thống kê tách khỏi I/O.

**Tech Stack:** Python ≥ 3.11, httpx, openai (cho DeepSeek), numpy, pandas, scipy, statsmodels, scikit-learn, matplotlib, python-dotenv, pytest; git; Claude Code CLI, Codex CLI.

**Spec:** `docs/specs/2026-11-21-c3-ai-code-review-design.md` (bản 3, cập nhật 2026-11-22). Đọc kèm `docs/related-work.md`.

## Global Constraints

- Dự án được review: **Java**; chỉ file `.java`; bỏ nhận xét ở phía code cũ (LEFT). Script: **Python**.
- Claude và GPT chạy qua **CLI bằng gói đăng ký** (Claude Code `claude -p`, Codex CLI `codex exec`); **DeepSeek qua API**. Khóa DeepSeek và GitHub token chỉ trong `.env`.
- Hai điều kiện: **chỉ đọc diff** (Claude Code tắt mọi công cụ; Codex trong thư mục trống, chỉ đọc; DeepSeek API) và **agent** (công cụ chỉ đọc trên bản checkout tại commit được review, **không chứa commit sau đó**; chỉ Claude Code và Codex).
- **Cùng một prompt** cho mọi công cụ; agent thêm đúng một câu cho phép đọc file trong repo. Đầu ra JSON `{file, line, comment, category}`.
- Điều kiện chính chạy **3 lần** mỗi (PR, mô hình); agent chạy **1 lần**. Phân tích chính dùng lần 1.
- Mỗi kết quả ghi: công cụ, phiên bản CLI, mô hình, cờ dòng lệnh, thời điểm, số token nếu có.
- D2: PR merged, **tạo sau mốc huấn luyện** (tham số), ≤ **500** dòng thay đổi `.java`, ≥ **2** nhận xét có thể hành động; nhận xét thực chất ≥ **10 từ** có tham chiếu code/từ khóa; loại PR > **30%** nhận xét bot; chỉ vòng review đầu.
- Lấy mẫu với seed **`20261121`**. Dữ liệu công bố **ẩn danh login GitHub** của người review.
- Danh mục 6 loại: `logic_bug`, `error_handling`, `performance`, `design_maintainability`, `testing`, `style_naming_docs`; ánh xạ sang 4 loại AACR-Bench.
- Ngưỡng **kappa ≥ 0,6** (người chấm–chuyên gia, người–người, giám khảo–người). CI **95%** bootstrap **theo PR**. Cochran's Q → McNemar exact từng cặp → **Holm**.
- Phân tích lực: phát hiện chênh lệch recall **10 điểm %**, α = 0,05 sau Holm, lực **0,8**.

## Review Focus

1. CLI trả lỗi, thoát mã ≠ 0, hết lượt dùng của gói đăng ký, hoặc in văn bản không phải JSON → ghi `run_error`, **không ghi vào cache**, lần chạy sau làm tiếp từ chỗ dừng; không bao giờ tính thành "AI không góp ý gì".
2. Bản checkout cho chế độ agent lỡ chứa commit sau commit được review → rò rỉ đáp án; phải kiểm chứng chỉ có đúng commit đó.
3. Tham chiếu có `line = null`, nằm file không phải `.java`, hoặc phía LEFT → bị loại và đếm lý do, không làm hỏng việc ghép.
4. Một tham chiếu khớp nhiều góp ý AI → recall đếm 1 lần; AI không góp ý nào → không gọi giám khảo, không chia cho 0.
5. Kappa khi hai bên đồng ý 100% với một nhãn duy nhất → 1,0, không phải NaN.

### Task 9: Checkout an toàn và AI review hai điều kiện

**Files:** Create `src/c3/checkout.py`, `src/c3/review.py`, `tests/test_checkout.py`, `tests/test_review.py`; Modify `src/c3/cli.py` (`review --reviewer claude|gpt|deepseek --mode diff|agent --runs N --dataset D1|D2|D3`).

**Interfaces:**
- Consumes: `Runner`, `PullRequest`, `AiComment`, `extract_json`, `CATEGORIES`.
- Produces:
  - `checkout.prepare_checkout(repo_url: str, sha: str, dest: Path) -> Path` — `git init`, `git fetch --depth 1 origin <sha>`, `git checkout --detach FETCH_HEAD`; sau đó kiểm tra `git rev-list --count HEAD == 1` và `HEAD == sha`, sai thì ném `RuntimeError`.
  - `review.build_review_prompt(pr: PullRequest, mode: Literal["diff","agent"]) -> tuple[str, str]` — prompt agent = prompt diff + đúng một câu cố định `AGENT_SENTENCE`; không chứa văn bản tham chiếu.
  - `review.ReviewResult(pr_id, reviewer, mode, run_idx: int, comments: list[AiComment], meta: dict, error: str | None, parse_error: bool)`.
